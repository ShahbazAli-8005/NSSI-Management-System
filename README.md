# NSSI Management System

A **C++ Object-Oriented Programming (OOP)** based management system developed for the **Namal Society for Social Impact (NSSI)**. The system was designed to manage the data and activities of different NSSI wings using file handling and core OOP concepts.

## Wings Covered

* **Education & Skill Development Wing** — Student, team, attendance, and duty management.
* **Blood Donation Wing** — Donor, blood group, contact, and donation record management.
* **Social & Welfare Wing** — Project, service, team, and fund management.
* **Emergency Response & Assistance Wing** — Student/faculty records, emergency cases, medicines, doctors, and dispensary management.

## Key Features

* File handling for storing and managing records
* Add, search, edit, delete, and display data
* Attendance and duty management
* Blood donor and emergency record management
* Project and fund management
* Dispensary and medicine management
* UML class diagrams for system design

## OOP Concepts

The project applies major **Object-Oriented Programming concepts**, including:

* Classes and Objects
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
